# ShotTracker

ShotTracker is an **R Shiny web application for basketball shot tracking and performance analysis**. It provides an interactive interface for recording and analysing player and team shooting data, with a focus on making basketball statistics accessible through a central dashboard.

## Features

* Player and team shot tracking
* Interactive basketball performance analysis
* Data visualisation through an R Shiny dashboard
* User authentication and login system
* Structured R-based application architecture
* Deployed using ShinyApps.io

## Technologies

* **R**
* **R Shiny**
* **MongoDB**
* **HTML / CSS / JavaScript**
* **Data Visualisation**

## Project Structure

* `app.R` — Main Shiny application
* `loginModule.R` — Authentication and login functionality
* `R/` — Supporting R functions and application logic
* `www/` — Web assets and styling
* `rsconnect/` — ShinyApps.io deployment configuration

## Purpose

The project was developed to explore the application of **data science and interactive dashboards to sports analytics**, providing a practical system for collecting, managing, and analysing basketball shooting data.
